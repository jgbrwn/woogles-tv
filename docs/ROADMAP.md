# Roadmap / ideas

Contributions welcome. Open an issue to discuss before starting on something big.

- Tune the TV layout for 720p devices, and test across more Android TV boxes and smart-TV browsers.
- More than two players (3–4 player games).
- Challenge modes besides void (single / double challenge with a phony-word penalty).
- Open a finished game straight in Woogles.io's analyzer (today: download its GCG file).
- An idle timeout for abandoned games in progress on the TV (finished games already make way after 20 minutes).
- More dictionaries supported by Macondo (e.g. other languages' letter distributions are already in `data/`).
- Announcer: more languages (it's English only today), and optional recorded voice packs.
- Prebuilt multi-arch container images and release binaries via CI (mind the word-list licensing when publishing images).
