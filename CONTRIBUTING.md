# Contributing

Thanks for your interest! Bug reports, ideas and pull requests are welcome.

- **Bugs / ideas:** open an issue. Screenshots (TV and phone) and your browser/TV device help a lot.
- **Pull requests:** keep them focused, run `gofmt`, `go vet ./...` and `go test ./...`, and update the docs if
  behaviour changes. See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for how to run it locally with a demo game.
- **Design:** the UI follows Woogles.io. New UI should work with a TV remote (D-pad + OK) on the TV side and with
  one thumb on the phone side, and in all six themes.
- **License:** contributions are accepted under the project's license (AGPL-3.0-or-later).
