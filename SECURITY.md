# Security policy

Woogles-TV is designed to run on the public internet without accounts. The threat model and protections are
described in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#security-model).

**Reporting a vulnerability:** please use GitHub's private vulnerability reporting
(*Security → Report a vulnerability* on https://github.com/jgbrwn/woogles-tv) rather than a public issue. Include
steps to reproduce and the version (commit) you tested. You can expect a reply within a week.

Only the latest commit on `main` is supported; please update before reporting.
